# SSCG canon re-pin — 2026-08-04 (`canon_d1`/`canon_d2`, 34-commit code drift + dataset frontier close)

Re-pins the SSCG canon after 34 commits landed on top of `canon_C3`'s pin (`1d920ae`,
`evaluation/CANON_20260803.md`), 27 of them touching non-test `.py` files that are
simultaneously indexed corpus and search path. Three clusters move behaviour rather than
just refactor it:

- **ADR-0025 index-clearing rework** (`9a7be53`, `fde9a44`, `66e31c0`, `9aeb7a6`) — in-place
  clears, BM25 rebuilt in place on resync. ADR-0025 itself deferred the canon re-pin to "a
  separate, standard post-landing step."
- **`e99ecef`** — two new relationship extractors (`GlobalUsageExtractor`,
  `TypeAssertionExtractor`) plus pruning of `assigns_to`/`reads_from`. Changes graph edges,
  which feed multi-hop expansion and ego-graph neighbours — the retrieval funnel, not just
  `find_connections`.
- **`a0792d2` + `220c0f6`** — `ImpactReport`'s 23 relationship fields consolidated into one
  dict.

Plus `ff1a6b5` (H064 retarget, one gold → three) already declared its own comparability
break before this session started — the published 131q figure in `CANON_20260803.md` does
not describe the dataset that landed alongside it.

**This record captures two baselines, separately attributed:**

- `canon_d1` — code drift only, captured immediately after the reindex and *before* any
  dataset edit (Phase 2).
- `canon_d2` — the expanded dataset only, captured after Phase 3's two H-query promotions
  land (Phase 4). The canonical (63q) and F-via-similar-view numbers are untouched by Phase 3
  and are not re-captured; `canon_d1`'s figures for those two views stand as final.

## Procedure

### Phase 1 — dataset validation + reindex

1. **Semantic re-validation** (the H064 class: gold resolves, but the behaviour the query
   names moved). Worklist: golds whose symbol name appears in a `1d920ae..HEAD` diff hunk —
   19 canonical (Q19, Q31–Q34, Q41, Q43, Q44, Q47, Q49, Q51, Q56, Q57, Q68, Q69, Q75, Q77,
   Q90, Q97) + 7 expanded-only (Q101, Q121, Q126, Q132, Q133, H062, H064). Every backing
   source file was diffed `1d920ae..HEAD` directly (`lsp_call_graph.py`, `intent_classifier.py`,
   `graph_storage.py`, and the rest): **zero retargets needed.** The ADR-0025 chain's edits
   are in-place-clear mechanics that don't touch the named classes/methods; the
   `_LspClient` change (Q132/Q133) is a resource-leak fix in `close()`, not `_dispatch`/
   `request`/`_reader_loop`; `intent_classifier.py`'s change (Q126) removes dead parameter
   writes, not `classify()`. H064 was already correctly retargeted pre-session (`ff1a6b5`).
2. **Full non-incremental reindex** (mandatory — `e99ecef`'s `uses_global`/`asserts_type`
   edges only populate on a full reindex): `cleanup_resources` (MCP, releases the
   `metadata.db` lock) then `tools/batch_index.py --path . --mode force` → **203 files, 2331
   chunks**, 64.66s (up from `canon_C3`'s 201/2310 — the two new relationship-extractor files
   from `e99ecef` account for the file-count delta).
3. `audit_golden_dataset.py` — **CLEAN** on both datasets (77q, 145q) against the fresh
   2331-chunk index.

  published baseline for all three views.
- **H064's retarget (`ff1a6b5`, one gold → three) is already priced into both datasets on

  dataset files, so it is not a new break introduced here.
- **An undocumented post-ADR-0025 capture predates this one and is superseded, not
  continued:** `sscg_adr0025_63q_r{1,2}.json` (pinned `804b5b8`, MRR 0.8323/0.8323, inside

  mid-run (`search/config.py`'s `enable_auto_reindex` defaults `True`,
  `max_index_age_minutes=30.0`, and a 131-query run takes ~10 minutes). Both predate `e99ecef`
  and the H064 retarget regardless. Cited here for the record; not reused as data.
- **`canon_d1`'s 131q figure (0.6654) describes the 145-query dataset, pre-Phase-3-promotion.**
  `canon_d2`'s figure (0.6591) describes the 147-query dataset, post-promotion (133 non-D

  the plan's Phase 2/4 split, and both deltas are stated above rather than folded into one
  number.
- **`canon_d2` is the current published baseline for the expanded (non-D) view going forward;
  `canon_d1`'s 131q figure is retained in this document only to isolate the dataset-change
  delta and is not itself a second "current" figure.**
- **Split-count citation correction** (see Phase 3 item 2 above): any published or planned
  document citing "43/16/18" or "86/28/31" as the *scored* train/val/test split is citing the

## ADR

**No new ADR this session.** The plan's own criterion is "only if a mechanism changed" —
